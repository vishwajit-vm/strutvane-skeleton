# strutvane-skeleton

> **Status: planned, not built yet.** This repository reserves the name and will hold the package when it is built. Nothing here is usable today.

**Skeleton**: The application template that `npm create strutvane` installs (the role laravel/laravel plays for Laravel).

| | |
|---|---|
| Package | none: this is an app template, not an npm package |
| Part of | [Strutvane](https://github.com/vishwajit-vm/strutvane), a TypeScript framework and package ecosystem for B2B apps, in the spirit of Laravel |
| Roadmap | phase 1, planned for the 0.2 line ([delivery plan](https://github.com/vishwajit-vm/strutvane/blob/main/docs/21-delivery-plan.md)) |
| Docs | https://vishwajit-vm.github.io/strutvane-docs/ |
| License | MIT |

When it is ready, `npm create strutvane@latest my-app` uses it as the starting point of every new app.
